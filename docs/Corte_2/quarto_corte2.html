segundo corte: analisis factoriales

1 MUESTREO

::: {style=“text-align: justify;”}

Para esta segunda etapa, donde vamos a realizar análisis factoriales, decidimos hacer una reducción de la base de datos con 97983 observaciones, 31 variables de las cuales hay 15cualitativas, 15 cuantitativas, y una variable que tiene la función de identificar las observaciones del estudiante. Esta reducción no es sinónimo de imputación de datos, sino un muestreo, donde tomamos como población la totalidad de observaciones, lo que nos permite tener un marco de lista, y que las probabilidades de inclusión de cada unidad de muestreo del diseño original por parte de PISA sean del mismo valor para todos; cabe aclarar que el curso no se enfoca en el muestreo o inferencia estadística, por lo que no vemos necesario calcular valores propios del diseño muestral para medir el efecto de este, por lo que no necesitamos estimar el tamaño de muestra adecuado para el total de la población. De este modo, usaremos un muestreo aleatorio simple, con un tamaño de 10000 unidades estadísticas, con el fin de reducir la capacidad de cómputo para los análisis posteriores. A continuación, usaremos la función slice_sample() que tomara la muestra, mostraremos la proporción de estudiantes por país en relación al tamaño inicial en la columna “Original”, también la misma proporción, pero respecto al tamaño de la muestra en “Submuestra”; además en la columna “Diferencia” tenemos la diferencia entre las proporciones originales y las muestrales con el fin de mostrar que no se introdujo un sesgo o desproporción en la muestra tomada. Finalmente, anexamos una salida gráfica como ayuda visual, donde comprobamos que las proporciones de observaciones por país se mantuvieron.

library(readr)
library(dplyr)
library(knitr)
library(kableExtra)
datos_pisa<- read_csv("base_final_pisa.csv")

set.seed(12345)
datos_c2 <- datos_pisa %>%
  slice_sample(n = 10000)
tabla_comparacion <- data.frame(
  Pais = names(prop.table(table(datos_pisa$CNT))),
  Original = round(as.numeric(prop.table(table(datos_pisa$CNT))) * 100, 2),
  Submuestra = round(as.numeric(prop.table(table(datos_c2$CNT))) * 100, 2)
) %>%
  mutate(Diferencia = round(Submuestra - Original, 2))
kable(
  tabla_comparacion, 
  digits = 2, 
  align = c("c", "r", "r", "r"),
  col.names = c("País", "Original (%)", "Submuestra (%)", "Diferencia (%)"),
  caption = "Verificación de Proporciones Muestrales por País"
) %>%
  kable_styling(
    full_width = FALSE, 
    position = "center", 
    bootstrap_options = c("striped", "hover", "condensed")
  )

library(dplyr)
library(ggplot2)
library(tidyr)

# 1. Calcular proporciones para el dataset original y la submuestra
df_prop_orig <- datos_pisa %>%
  filter(!is.na(CNT)) %>%
  count(CNT) %>%
  mutate(Porcentaje = (n / sum(n)) * 100, Tipo = "Original (N = 97.983)")

df_prop_muestra <- datos_c2 %>%
  filter(!is.na(CNT)) %>%
  count(CNT) %>%
  mutate(Porcentaje = (n / sum(n)) * 100, Tipo = "Muestra  (N = 10.000)")

# 2. Unificar los datos para graficar
df_comparacion <- bind_rows(df_prop_orig, df_prop_muestra)

# 3. Graficar la comparación de proporciones
ggplot(df_comparacion, aes(x = reorder(CNT, Porcentaje), y = Porcentaje, fill = Tipo)) +
  geom_bar(stat = "identity", position = "dodge", width = 0.7) +
  geom_text(aes(label = sprintf("%.1f%%", Porcentaje)), 
            position = position_dodge(width = 0.7), 
            hjust = -0.15, size = 2.8, fontface = "bold") +
  coord_flip() +
  scale_fill_manual(values = c("#FB8500", "#023047")) +
  labs(
    title = "Validación de Muestreo Aletorio Simple (N = 10.000)",
    subtitle = "Comparación de proporciones de estudiantes por país en PISA 2022",
    x = "País de Origen (CNT)",
    y = "Porcentaje Muestral (%)",
    fill = "Grupo"
  ) +
  theme_minimal(base_size = 11) +
  theme(
    plot.title = element_text(face = "bold", size = 14, color = "#023047"),
    axis.text.y = element_text(face = "bold", color = "black"),
    legend.position = "top",
    panel.grid.major.y = element_blank()
  )
