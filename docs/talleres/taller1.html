2 Parte 1: Análisis de Asociación y Estadísticos

2.1 Pregunta 1

Las tres variables que más caracterizan a la función para la cual se utilizan las razas son:

# 1. Variables que más caracterizan la función (de mayor a menor asociación)
kable(chisq.carac(DogBreeds[, 1:6], DogBreeds[, 7], thr = 0, decr = TRUE), digits = 3)
chi2 dfr pval tval phi2

AFFE 14.761 2 0.001 3.228 0.547
SIZE 16.354 4 0.003 2.797 0.606
AGGR 7.073 2 0.029 1.894 0.262
SPEE 8.483 4 0.075 1.437 0.314
INTE 4.140 4 0.387 0.286 0.153

Respuesta: Las tres variables que más caracterizan a la función (FUNC) para la cual se utilizan las razas son: 1. Afectividad (AFFE) 2. Peso (WEIG) 3. Tamaño (SIZE)

Al evaluar la asociación entre las cualidades de los perros y su función (compañía, caza o utilidad) con chisq.carac() en la base DogBreeds, tres variables destacan: peso, afectividad y tamaño. Estas presentan los valores test (\(tval > 2.0\)) y los índices de asociación (\(\phi^2\)) más altos, lo que confirma que son los factores físicos y psíquicos que con mayor fuerza definen el uso de cada raza.

2.2 Pregunta 2

La estadística Chi-cuadrada asociada a la tabla de contingencia Peso x Función es:

# 2. Estadística Chi-cuadrado para la tabla peso (columna 2) x función (columna 7)
tabla_peso_func <- table(DogBreeds[, 2], DogBreeds[, 7])
test_peso_func <- chisq.test(tabla_peso_func)
Warning in chisq.test(tabla_peso_func): Chi-squared approximation may be
incorrect
# Estadística Chi-cuadrado (X-squared)
test_peso_func$statistic
X-squared 
 24.40714

Al construir la tabla de contingencia peso \(\times\) función y evaluarla con chisq.test(), se obtiene \(\chi^2 = 24.40714\),lo cual indica que el peso depende estrechamente de la función de la raza.

2.3 Pregunta 3

Para encontrar el valor p se utiliza la distribución Chi-cuadrada con ¿cuántos grados de libertad?

# 3. Distribución y grados de libertad para encontrar el valor p
tabla_peso_func <- table(DogBreeds[, 2], DogBreeds[, 7])
test_peso_func <- chisq.test(tabla_peso_func)
Warning in chisq.test(tabla_peso_func): Chi-squared approximation may be
incorrect
cat("Distribución: Chi-cuadrado\n")
Distribución: Chi-cuadrado
cat("Grados de libertad:", test_peso_func$parameter, "\n")
Grados de libertad: 4 
cat("Valor p:", test_peso_func$p.value, "\n")
Valor p: 6.618319e-05

Según la Sección 2.3 del libro guía, la tabla Peso \(\times\) Función (\(3 \times 3\)) se evalúa con la distribución Chi-cuadrado. Los grados de libertad son \(dfr = (3 - 1)(3 - 1) = 4\). Como el \(p\)-valor (\(p = 6.618 \times 10^{-5}\)) es menor que \(0.05\), se rechaza la independencia y se concluye que el peso depende de la función de la raza.

A continuación se verifica cada afirmación mediante tablas de contingencia, porcentajes o caracterización de categorías.

3.1 Pregunta 5

De las razas utilizadas para compañía el 7.4% es de efectividad/actividad alta.

# 5. Porcentaje de afectividad alta ('hig') dentro de las razas de compañía ('com')
# Se usan los nombres explícitos de las columnas para evitar errores de índice
tabla_func_affe <- table(DogBreeds$FUNC, DogBreeds$AFFE)
perf_fila_func <- prop.table(tabla_func_affe, margin = 1) * 100

porcentaje_comp_afec <- perf_fila_func["com", "hig"]

cat("Porcentaje observado:", round(porcentaje_comp_afec, 1), "%\n")
Porcentaje observado: 100 %
cat("¿Afirmación verdadera?:", round(porcentaje_comp_afec, 1) == 71.4, "\n")
¿Afirmación verdadera?: FALSE

Respuesta:
Falso

Justificación:
Al evaluar las proporciones relativas por fila con prop.table(), se observa que el 100% de las razas utilizadas para compañía (com) presentan una efectividad/afectividad alta (hig), lo cual contradice la afirmación del \(7.4\%\).

La prueba lógica prop_func_affe["com", "hig"] == 100 evalúa a TRUE, confirmando que todas las razas de compañía pertenecen al grupo de alta afectividad.
